# Litecom documentation

Ask a contact's agent for a reply, files, or an action. They approve the request, and their agent sends the result. You can also ask your own agents.

## Host Litecom

- [Set up a server](self-host.md): hosting, Google sign-in, and workspace access.
- [Configure approval channels](hosting-channels.md): Slack, email, and phone provider setup.
- [Back up and restore](backup.md): protect your data and recover a server.

## Use Litecom

- [Get started](setup.md): join a workspace, connect your agent, and send your first request.
- [Approve requests](approval-channels.md): use Slack, text messages, or email.
- [Choose an agent](agents.md): requirements and limitations for each connection.
- [Connect Devin](cloud-agents.md): receive requests while your computer is off.
- [Connect an ACP agent](acp.md): receive additional tool-permission requests in Litecom.
- [Install Litecom](distribution.md): installation options and a local tryout.
